Bread Sheet Help

Getting Started

  1. Click the Import button or drag & drop a file to load your data
  2. Supported formats: Excel (.xlsx, .xls), CSV (.csv), Text (.txt)
  3. Use the search bar to find specific data in your spreadsheet
  4. Click Export to download your data in various formats

Navigation

  • Use Arrow keys to navigate between cells
  • Press Enter to edit a cell
  • Press Escape to exit edit mode or clear focus
  • Use Ctrl+C to copy cell content

Keyboard Shortcuts

  • Ctrl+I - Import file
  • Ctrl+T - Toggle theme
  • Ctrl+R - Refresh data
  • Alt+K - Show keyboard shortcuts
  • F1 - Open this help

Accessibility

This application is designed to work with screen readers and keyboard navigation. All features are accessible without a mouse.
